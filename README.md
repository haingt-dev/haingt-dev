# Hi, I'm Hải.

I took the long way round to making games.

I make games full-time at [Disa Games](https://disagames.com), my indie studio in Ho Chi Minh City. Right now I'm building [Clockwork Brood](https://disagames.com/clockwork-brood/) in Godot: an insect kingdom builds a giant machine in its own image, and you're the engineer who puts it together and decides how it fights.

Before this came about seven years of backend work, and a few game ideas I built and set down, each one leaving plenty of lessons. Since 2016 I've also been a co-founder of [Bookie](https://www.bookiecommunity.com/), a Vietnamese reading community.
